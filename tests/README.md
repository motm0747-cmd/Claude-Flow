# 테스트

```bash
node tests/run.mjs              # 전부 (약 3분)
node tests/run.mjs prepay ui    # 이름에 그 글자가 든 것만
```

러너가 정적 서버를 직접 띄우므로 준비 과정이 없습니다. 필요한 건 **Playwright(Chromium)** 뿐이고, `tests/lib/env.mjs` 가 설치 위치를 찾습니다 — 못 찾으면 거기에 경로를 추가하세요.

포트는 `CF_TEST_PORT`(기본 8199), 하위 경로용은 `CF_TEST_SUBPORT`(기본 8201)로 바꿀 수 있습니다.

## 왜 이렇게까지 하나

이 앱의 계산은 한 줄로 이어져 있습니다.

```
카드 사용 → 전월 실적 → 혜택 구간 → 적립 → 청구할인
        → 카드 미결제 → 결제일 → 현금흐름 → 쓸 수 있는 돈
```

하나가 틀리면 **홈의 대표 숫자가 틀립니다.** 그런데 그게 틀렸다는 걸 화면만 봐서는 알 수 없습니다 — 그럴듯한 숫자가 나오니까요. 그래서 계산은 전부 테스트로 고정해 둡니다.

| `smoke` `invariants` `final` | 로드·기본 불변식·최종 점검 |

| `newphone` | 폰을 바꿨을 때 — 빈 기기가 클라우드를 덮어쓰지 않고 그대로 받아오는지 |
| `perk` `exempt` `hana.check` | 카드 혜택 엔진, 발급 첫 달 실적 면제, 하나 MOVING 실제 값 대조 |
| `prepay` | 선결제 — 매주 자동·건별·잔액 부족 보류 |
| `start` | 개시 스냅샷·진행 중 할부·시작 마법사·할부 혜택 제외 |
| `home` `ui` `pc` | 홈 3단 구조, 화면 정리, 넓은 화면 배치 |
| `feat` `feat2` `inv` `flow` | 순자산 흐름·리밸런싱·목표, 투자 수수료·환전, 현금흐름 |
| `click` | 실제 DOM 클릭 (3개 기기) — `onclick` 이 깨져도 조용히 지나가지 않게 |
| `subpath` | GitHub Pages 하위 경로(`/Claude-Flow/`) 배포 |
| `audit` | 6종 화면 × 라이트/다크 레이아웃 넘침·겹침 |
| `digest` `digest2` `webpush` | 서버 알림 계산, Web Push 암호화(RFC 8291·8292) |

## 규칙

- **실패는 `❌` 로 시작하는 줄**로 찍습니다. 러너가 그걸 세므로 형식을 지켜주세요.
- 판정마다 **실제 값을 함께 출력**합니다. 빨간 줄만 보고 원인을 알 수 있어야 합니다.
- 버그를 고칠 때는 **고치기 전 상태로 되돌려 그 테스트가 실제로 실패하는지** 확인하고 넣습니다. 통과만 하는 테스트는 아무것도 지켜주지 않습니다.
- 외부망(폰트 CDN·환율 API)이 막힌 환경에서도 전부 통과해야 합니다. 폴백 동작은 각 기능 테스트가 따로 봅니다.
